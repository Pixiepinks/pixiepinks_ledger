# Staff quoted replies in the WhatsApp Inbox

Choose **Reply** beneath a customer message, type a response (or select and edit a Quick Message), then send. The selected message appears in a compact preview above the composer. Cancel removes only the quote; leaving/switching the conversation clears the quote. Replying with text to a customer's voice, photo or document is supported when the original provider message reference is retained. Old messages without a provider reference have no Reply action.

This version sends quoted **text and Quick Messages**. Voice recordings, Saved Voices, products and attachments keep their existing sending workflows. While a text quote is selected, their controls ask staff to cancel it first, so the application cannot silently send an unquoted message instead. Consent requests are kept separate from quoted replies.

The server resolves a local message ID within the authorized conversation, rejects ambiguous/missing/cross-customer references and requires CSRF plus the existing ownership/sharing and 24-hour reply-window checks. The existing WhatsApp text transport adds `context.message_id` only for quoted sends. The outgoing history persists the reference, so the existing quote preview and navigation work after refresh. A transport mismatch never triggers an unquoted fallback or automatic resend. Uncertain no-ID acceptance retains the existing durable claim and does not report a confirmed send.

Migration `20261107_27`, after `20261107_26`, adds nullable VARCHAR(255) `whatsapp_manual_sends.reply_to_whatsapp_message_id`. It binds idempotency to the quote as well as conversation, sender, text and Quick Message. Existing rows stay NULL. The outgoing message history column already existed; no audio or consent schema changes are required. Upgrade before starting this application version; downgrade retains the added column and retry evidence. Application rollback uses the previous application version with additive schema retained.

No customer messages, production migrations, deployments, environment changes, Global AI switches or audio encoding changes were performed. Tests use mocked Meta requests and isolated databases.
